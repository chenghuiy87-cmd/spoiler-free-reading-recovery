# The physical-book restart card

When a reading session is interrupted for a few days, a bookmark answers only one question: **where did I stop?** This small restart card also preserves **what had my attention** and **what I wanted to notice next**, without copying a passage or writing a plot summary.

## The 30-second card

Before closing the book, record:

1. **Page** — the page where you stopped.
2. **Moment** — choose one: `Keep`, `Felt`, `Clue`, or `Discuss`.
3. **Strength** — `1`, `2`, or `3`.
4. **Return cue** — one short question for your future self, such as “Why did this decision feel risky?”

Do not quote the book. Do not explain what happens next. The card should make sense to you while remaining uninteresting to anyone trying to find spoilers.

```text
BOOK:
PAGE:
MOMENT: Keep / Felt / Clue / Discuss
STRENGTH: 1 / 2 / 3
RETURN CUE:
```

The repository also includes a [blank Markdown card](reading-restart-card.md) that can be copied into Notes or printed.

## How to restart

- Read the card before reopening the book.
- Return to the recorded page and scan only enough to recover the scene.
- Keep the return cue in mind for the next few pages.
- Replace the card when a new interruption point appears.

## What this is—and is not

This is a lightweight continuity tool for leisure reading. It is not a replacement for quotations, citations, academic notes, or a full reading journal.
