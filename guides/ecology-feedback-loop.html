The feedback-loop card for ecology reading

Ecological explanations often involve loops rather than a single cause. This card identifies direction, delay, and limit in one described system.

Build the card

Save one page where this method becomes useful. Complete the fields in your own words so the page remains the route back to the source.

FieldPrompt
ChangeWhat quantity increases or decreases?
ResponseWhat part of the system reacts?
ReturnHow does that response affect the original change?
LimitWhat resource, delay, or threshold constrains the loop?

Run the check

  • Label the loop reinforcing or balancing only after tracing the return path.
  • Look for a time delay that can hide the response.
  • Keep local evidence separate from claims about all ecosystems.

Working sentence: My current reading is ______________________________.

Review rule

Redraw the loop after the example and mark the link with the greatest uncertainty.

Boundaries

This is a personal reflection aid, not a quotation archive, plot substitute, academic citation, factual verification, or proof of an author's intention. Return to the full passage before making consequential claims.
