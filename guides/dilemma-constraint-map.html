The constraint map for ethical dilemmas in fiction

A moral choice looks simpler when the reader ignores urgency, information, obligation, and power. This map tests the constraint before judging the character.

Build the card

Save one page where this method becomes useful. Complete the fields in your own words so the page remains the route back to the source.

FieldPrompt
OptionsWhat choices are genuinely available?
KnowledgeWhat can the character know now?
ObligationWho has a legitimate claim on them?
PowerWho bears consequences without choosing?

Run the check

  • Remove options that require knowledge or power the character lacks.
  • Name the cost shifted onto another person.
  • Separate tragic constraint from convenient excuse.

Review rule

Re-evaluate after consequences appear, but preserve what was unknowable at the decision page.

Boundaries

This is a personal reflection aid, not a quotation archive, plot substitute, academic citation, factual verification, or proof of an author's intention. Return to the full passage before making consequential claims.
