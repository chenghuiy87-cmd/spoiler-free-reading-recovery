Spoiler-light reading tool

The perspective-switch card for multi-viewpoint novels

A viewpoint change can alter what counts as evidence, danger, or fairness. This card helps a reader reorient without summarizing the plot.

Build the card

Save one page where this method becomes useful. Complete the fields in your own words so the page remains the route back to the source.

FieldPrompt
VoiceWhose perceptions organize this section?
AccessWhat can this viewpoint know directly?
Blind spotWhat remains outside their knowledge?
ReframeWhich earlier event now looks different?

Run the check

  • Name one fact this viewpoint witnessed and one it only inferred.
  • Notice a repeated event whose emotional meaning has changed.
  • Keep disagreement between viewpoints unresolved until the text supplies evidence.

Working sentence: My current reading is ______________________________.

Review rule

After two pages, revise the blind spot only if the new viewpoint gains direct access.

Boundaries

This is a personal reflection aid, not a quotation archive, plot substitute, academic citation, factual verification, or proof of an author's intention. Return to the full passage before making consequential claims.
