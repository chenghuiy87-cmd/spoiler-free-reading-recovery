Spoiler-light reading tool

The minor-character return note

A briefly seen character can return with new information, leverage, or emotional weight. This note preserves the first function so the return can be read as change rather than surprise alone.

Build the card

Save one page where the method becomes useful. Complete the fields in your own words.

FieldPrompt
First roleWhat did the character do in the earlier scene?
ConnectionWho or what linked them to the main action?
ReturnWhat new access, need, or knowledge appears?
EffectWhich relationship or expectation changes?

Run the check

  • Do not upgrade every named person into a future clue.
  • Compare behavior, not only description.
  • Notice whether the return closes an old line or opens a new one.

Working sentence: My current reading is ______________________________.

Review rule

After the return scene, write one sentence about why this character—not a new one—was needed.

Boundaries

This is a personal reflection aid, not a quotation archive, plot substitute, academic citation, factual verification, or proof of an author's intention. Return to the full passage before making consequential claims.
