Spoiler-light reading tool

The invented-term decoder for speculative books

A coined word can name an object, institution, rank, ritual, or prejudice. This decoder builds meaning from use while protecting the uncertainty that makes discovery enjoyable.

Build the card

Save one page where this method becomes useful. Complete the fields in your own words so the page remains the route back to the source.

FieldPrompt
TermWhat unfamiliar word appears?
GrammarWhat role does it play in the sentence?
ActionWhat do people do with, to, or because of it?
StatusWho understands or controls it?

Run the check

  • Collect two uses before fixing a definition.
  • Prefer behavior and consequence over sound-based guesses.
  • Keep cultural meaning separate from literal function.

Working sentence: My current reading is ______________________________.

Review rule

Write a provisional definition that includes one uncertainty, then revisit only when a new use changes it.

Boundaries

This is a personal reflection aid, not a quotation archive, plot substitute, academic citation, factual verification, or proof of an author's intention. Return to the full passage before making consequential claims.
