The chronology-braid map for nonlinear narratives

Nonlinear books can be clear within each strand while still making the braid hard to hold. This map tracks transitions rather than reconstructing every date.

Build the card

Save one page where this method becomes useful. Complete the fields in your own words so the page remains the route back to the source.

FieldPrompt
StrandWhich time period is active?
AnchorWhat event locates it relative to another strand?
CarryoverWhich question crossed the transition?
DifferenceWhat does this strand know that another does not?

Run the check

  • Use relative order when exact dates are unavailable.
  • Mark a memory inside a strand separately from a full timeline switch.
  • Follow one repeated object or question across the braid.

Working sentence: My current reading is ______________________________.

Review rule

When strands meet, note what new causal connection becomes possible rather than flattening them into one summary.

Boundaries

This is a personal reflection aid, not a quotation archive, plot substitute, academic citation, factual verification, or proof of an author's intention. Return to the full passage before making consequential claims.
