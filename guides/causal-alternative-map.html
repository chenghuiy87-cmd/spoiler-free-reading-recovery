The causal-alternative map for explanatory nonfiction

A confident causal story can hide selection, reverse direction, or a common cause. This map keeps alternatives visible without dismissing the author's explanation.

Build the card

Save one page where this method becomes useful. Complete the fields in your own words so the page remains the route back to the source.

FieldPrompt
OutcomeWhat change needs explaining?
Main causeWhat cause does the author propose?
AlternativeWhat else could produce the outcome?
DiscriminatorWhat observation would separate the explanations?

Run the check

  • Draw the direction of each proposed link.
  • Ask whether cause and outcome could influence each other.
  • Look for a shared condition that affects both.

Working sentence: My current reading is ______________________________.

Review rule

After the evidence section, rank explanations by support and mark what remains untested.

Boundaries

This is a personal reflection aid, not a quotation archive, plot substitute, academic citation, factual verification, or proof of an author's intention. Return to the full passage before making consequential claims.
