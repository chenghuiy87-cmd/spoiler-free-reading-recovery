The denominator card for statistics in prose

Percentages feel precise even when the underlying group is unclear. This card restores the denominator, time window, and comparison before interpretation.

Build the card

Save one page where this method becomes useful. Complete the fields in your own words so the page remains the route back to the source.

FieldPrompt
NumeratorWhat event or group is being counted?
DenominatorOut of how many eligible cases?
WindowOver what time period?
ComparisonRelative to what baseline or group?

Run the check

  • Translate one percentage into approximate counts when possible.
  • Check whether the denominator changed between comparisons.
  • Separate absolute change from relative change.

Working sentence: My current reading is ______________________________.

Review rule

If a denominator is unavailable, record the measurement as incomplete instead of treating it as zero.

Boundaries

This is a personal reflection aid, not a quotation archive, plot substitute, academic citation, factual verification, or proof of an author's intention. Return to the full passage before making consequential claims.
